# Historical design documents

These documents preserve selected contributions from bibr's private development
before its public release. They describe earlier designs and are not current API
specifications.

`metacheck_paper_structure.qmd` records the January 2026 paper-object design and
Lisa DeBruine's changes to the text identifiers and section hierarchy. Its three
historical versions were imported with their original authors and author dates;
the import commits identify their source commits. The public repository does not
contain the complete private development history.

For the current contract, see the [JSON schema documentation](https://bibr.org/reference/schema/).
