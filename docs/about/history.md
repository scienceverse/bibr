# Project history and contributors

bibr began private development in December 2025. The public repository starts
from a reviewed source snapshot for the 0.5.0 release. The original development
history is preserved privately, alongside internal evaluation material.

[Lisa DeBruine](https://github.com/debruine) contributed to the early Metacheck
paper-object design. Her January 2026 changes clarified text identifiers and
the parent-child relationships between sections. We have preserved those
contributions, with their original authorship and dates, in the
[historical design archive](https://github.com/scienceverse/bibr/tree/main/history).

The archive describes an earlier design. Refer to the
[current JSON schema](../reference/schema.md) for the supported export format.
The public commit history represents the public release and selected historical
contributions, rather than the complete development record.
